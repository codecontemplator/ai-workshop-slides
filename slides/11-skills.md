## Skills

Reusable, structured prompts for specific tasks.

### What are skills?

- Modular prompt templates triggered by context
- Inject specialized instructions and workflows
- Still just prompt engineering - but organized and repeatable

### Example:

A "code review" skill might inject:

- Persona: senior engineer
- Rules: check for security issues, performance, naming
- Output format: bullet points with severity levels

> Skills scale prompt engineering from one-off instructions to a library of reusable behaviors.
